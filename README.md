# Serrago's Swimmers website (modern)

Modern redesign with the same content for serragosswimmers.com, private swim lessons in Albany, NY.

Plain static HTML/CSS with no build step. Open `index.html` in a browser, or upload the folder's contents to any static host (GitHub Pages, Netlify, cPanel, etc.).

## Pages
- `index.html` – Private swim lessons (home)
- `childrens-swim-lessons.html`
- `adult-swim-lessons.html`
- `triathlete-swim-lessons.html`
- `triathlete-swim-training.html`
- `special-needs.html`
- `meet-the-swim-coaches.html`
- `strength-training.html`
- `testimonials.html`
- `blog.html`

Images are in `images/`.
